# Tetris

Unity(6000.3.21f1)로 만든 2D 테트리스 게임입니다.

## 게임 소개

10칸 × 20칸 보드 위에 7가지 표준 테트로미노(I, O, T, S, Z, J, L)가 랜덤으로 떨어집니다.
블록을 좌우로 옮기고 회전시켜 바닥에 쌓고, 가로 한 줄을 완전히 채우면 그 줄이 사라지면서 점수를 얻습니다.
줄을 지울수록 레벨이 올라가고, 레벨이 오를수록 블록이 점점 빨리 떨어집니다.
쌓인 블록이 보드 맨 위(블록이 새로 생성되는 자리)까지 닿으면 게임 오버입니다.

## 조작 방법

| 키 | 동작 |
| --- | --- |
| ← / → | 블록 좌우 이동 |
| ↑ | 블록 회전 (시계방향 90도) |
| Space (누르고 있기) | 소프트 드롭 — 누르고 있는 동안 블록이 빠르게 떨어짐 |

## 주요 기능

- **7종 테트로미노**: 각기 다른 모양과 색상을 가진 표준 블록 (I, O, T, S, Z, J, L)
- **다음 블록 미리보기**: 화면 좌측 상단 NEXT 패널에서 다음에 나올 블록을 미리 확인
- **줄 삭제**: 가로 한 줄이 가득 차면 삭제되고, 위쪽 블록들이 한 칸씩 내려옴
- **클래식 점수 테이블**: 한 번에 여러 줄을 지울수록 비례 이상의 점수를 획득 (싱글 40 / 더블 100 / 트리플 300 / 테트리스 1200, 레벨 배율 적용)
- **레벨 시스템**: 10줄을 지울 때마다 레벨이 오르고, 레벨에 비례해 낙하 속도가 빨라짐 (최저 낙하 간격 0.1초로 제한)
- **소프트 드롭**: 스페이스바를 누르고 있으면 블록을 빠르게 떨어뜨릴 수 있음
- **게임 오버 & 재시작**: 블록이 쌓여 게임이 끝나면 최종 점수를 보여주는 결과 화면이 뜨고, Restart 버튼으로 바로 다시 시작 가능
- **최고 점수(High Score)**: 지금까지 기록된 최고 점수를 화면 좌상단에 표시. 실행 중에는 Restart 버튼으로 재시작해도 기록이 유지되지만, 게임을 완전히 껐다 켜면(새 세션 시작) 0으로 초기화됨

## 스크립트 구성

| 스크립트 | 역할 |
| --- | --- |
| `Board.cs` | 보드 칸 데이터 관리, 줄 삭제 로직, 보드 테두리 표시 |
| `TetrominoShapes.cs` | 7가지 블록의 모양(좌표)과 색상 정의 |
| `Piece.cs` | 현재 떨어지는 블록의 이동/회전 처리 |
| `GameManager.cs` | 낙하 타이머, 블록 고정, 게임 오버 등 게임 전체 흐름 관리 |
| `ScoreManager.cs` | 점수/레벨/최고 점수 계산 및 표시 (최고 점수는 실행 세션 동안만 유지) |
| `NextPiecePreview.cs` | 다음 블록 미리보기 UI |
| `GameOverUI.cs` | 게임 오버 결과 화면 표시 |
| `RestartButton.cs` | 재시작 버튼 클릭 시 씬 재시작 |
| `SquareSprite.cs` | 블록 한 칸을 그리는 테두리 있는 사각형 스프라이트 생성 |

## 실행 방법

1. Unity Hub에서 `6000.3.21f1` 버전으로 이 프로젝트를 엽니다.
2. `Assets/Scenes/SampleScene.unity` 씬을 열고 Play 버튼을 누릅니다.
